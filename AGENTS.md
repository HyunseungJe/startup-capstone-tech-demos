# Repository instructions

## Project placement

- Before creating or moving files, inspect the repository root and read every applicable `AGENTS.md` file.
- Create every new demo project under the next numbered path, such as `demos/02-name/` or `demos/03-name/`.
- Do not create demo project directories at the repository root.
- Keep each demo self-contained inside its own directory, including its `pyproject.toml`, source files, README, and project-specific configuration.
- When commands, documentation, or links contain a demo path, use its canonical numbered location under `demos/`.

## Verification

- Before reporting completion, verify that the demo exists under `demos/` and that no duplicate project directory remains at the repository root.
